# AutoDL Watch

一个轻量的 Windows 桌面监测工具，用来观察 AutoDL 普通容器实例的状态，并在实例恢复可用时提醒或尝试开机。

它适合这样的场景：你正在通过 SSH 使用 AutoDL，但目标实例因为 GPU 库存或平台状态暂时无法启动，希望用一个很小的悬浮提示持续观察，而不必反复刷新网页。

> 本项目是非官方工具，与 AutoDL 无隶属或合作关系。它使用 AutoDL 网页控制台当前使用的接口；网页接口发生变化时，相关功能可能失效。

## 功能

- 显示当前监测状态、实例状态和最近一次检查结果
- 从已登录的 AutoDL 网页会话读取普通容器实例
- 在设置界面选择目标实例，并自动带出 GPU 规格 ID 和显示名称
- 支持“仅提醒”和“自动开机”模式
- 自动操作冷却，避免短时间内重复提交
- 成功开机后自动暂停监测
- 本地 CSV 操作日志
- 登录会话令牌使用 Windows DPAPI 加密，只能由当前 Windows 用户解密
- 小型悬浮 UI，可拖动、置顶，并通过右键菜单打开设置

## 当前限制

- **自动克隆/创建普通实例尚未启用。** AutoDL 普通实例的克隆接口还需要进一步验证，界面中的相关能力仅作预留。
- 自动开机可能立即产生费用；本工具不会自动关机，也不会自动释放实例。
- 目前面向 Windows 10/11，网页登录流程依赖 Microsoft Edge。
- 网页会话可能过期。遇到登录超时或读取失败时，请在设置中重新执行“登录 AutoDL 网页”。

## 环境要求

- Windows 10/11
- Python 3.10 或更高版本
- Microsoft Edge

项目只使用 Python 标准库，无需安装第三方依赖。

## 快速开始

1. 下载或克隆本仓库。
2. 双击 `run.bat` 启动悬浮窗。
3. 右键悬浮窗，打开“设置”。
4. 点击“登录 AutoDL 网页”。程序会打开一个临时 Edge 窗口；请在其中手动完成登录。
5. 返回设置页刷新实例，选择需要监测的实例。
6. 首次使用建议选择“仅提醒”，确认读取结果正确后再启用“自动开机”。
7. 保存设置并开始监测。

也可以在终端中启动：

```powershell
python main.py
```

## 安全与隐私

- 程序不会读取或保存你的 AutoDL 密码。
- 网页会话令牌经过 Windows DPAPI 加密后保存在本地 `config.json` 中。
- `config.json`、运行日志、缓存和临时浏览器数据均已加入 `.gitignore`，不会进入 Git 仓库。
- 请勿把配置文件、日志或会话令牌发送给他人。

## 风险提示

启用“自动开机”即代表你授权程序在满足条件时提交开机请求。开机成功后，AutoDL 可能按其计费规则开始计费。请先用“仅提醒”模式验证目标实例与状态，并自行关注实例的关机和释放。
